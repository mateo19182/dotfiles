# Working with me

- Answer first, concisely. Say what you verified and what you inferred.
- Smallest change that works. Few comments, only for a non-obvious why.
- Ask only on real decisions, with concrete options; check what you can yourself.
- Reply in my language (Spanish from Spain when I write Spanish).
- Ask before anything that reaches another person: messages, emails, tickets, PR comments, deploys, shared or prod DB writes.
- Never expose secrets in files or chat.
- Notify me only when I ask: `hermes send -q --to telegram "<project>: <status>: <what I need to do>"`.
- Edit skills in `~/dotfiles/agents/skills`, not in the agent's skills folder.
